Reinforcement Learning

RecoveryDAgger

In this project, we built RecoveryDAgger, a query-efficient imitation learning method that helps agents recover from risky or unfamiliar states before asking an expert for help. Starting from DAgger, we added a recovery policy with ensemble Q-networks and tested it in Gymnasium PointMaze.

Color mixer

We built a smart Color Mixer that turns digital or scanned colors into real paint. Powered by Mixbox + Kubelka–Munk models, it automatically mixes the target color while the UI monitors the machine’s current status for a smoother experience. It was my first project in NTUEE, and it's very interesting to me!
